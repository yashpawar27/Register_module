# Register_module
This project used mostly simple logic gates, such as AND, OR, invert, and D-type flip-flop to create a register. These ICs work together in parallel to create a functioning register module capable of containing 1 bit of data. 

Parts list:
- 1x SN74LS04N
- 1x SN74LS08N
- 1x SN74LS32N
- 1x SN74LS74N

Credit goes to Ben Eater providing the schematics/tutorial for this project. https://eater.net/8bit/registers
